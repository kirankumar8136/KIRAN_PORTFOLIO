# Kiran Kumar K — Next-Gen React 3D Cyber Portfolio

High-performance, futuristic portfolio built with **React 19**, **Three.js (WebGL)**, and **Vite**.

## 🚀 Quick Start

### 1. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 2. Build for Production
```bash
npm run build
```
Generates optimized static assets in the `dist/` directory.

### 3. Preview Production Build
```bash
npm run preview
```
